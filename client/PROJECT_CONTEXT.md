Project Name:
SpendWise

Purpose:
A modern expense tracker where users can manage income and expenses, view analytics, and stay within budget.

Tech Stack:

- React 19
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM
- Axios
- Express.js backend
- MongoDB

Important Rules:

- Do not generate backend code.
- Do not modify Express endpoints.
- Do not use TypeScript.
- Do not use CSS Modules.
- Do not use Styled Components.
- Use only Tailwind CSS.
- Keep components reusable.
- Use functional components.
- Use React Router Link for internal navigation.
- Use Axios for API calls.
- Authentication uses HTTP-only cookies.
- Never store JWT in localStorage or sessionStorage.
- Keep components clean and production ready.
